# Week 02 Project: Contacts Part 2 Video Script

Use this after the Contacts API is connected to MongoDB and deployed to Render.

## Links To Submit

- GitHub repository link
- Render published API link
- YouTube video link

## What To Show

1. Open the Render URL.
2. Open `/api-docs`.
3. In Swagger, test `GET /contacts`.
4. In Swagger, test `GET /contacts/{id}`.
5. In Swagger, test `POST /contacts` and create a new contact.
6. Open MongoDB Compass and show the new contact in the database.
7. In Swagger, test `PUT /contacts/{id}` and update the contact.
8. Open MongoDB Compass and show that the contact changed.
9. In Swagger, test `DELETE /contacts/{id}`.
10. Open MongoDB Compass and show the contact is gone.
11. Submit invalid data and show that the API returns a 400 validation response.
12. Show that `.env` and `node_modules` are not pushed to GitHub.

## Simple Explanation To Say

Swagger is both documentation and a testing page. It tells another developer which routes exist, what data each route expects, and what responses the API can return.
